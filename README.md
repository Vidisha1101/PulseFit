## 📌 Overview

**PulseFit** is a web-based fitness tracking application that helps users log, monitor, and visualize their workout progress. Built with Streamlit for rapid deployment, PulseFit gives you a clean and interactive interface to stay on top of your fitness journey — no complex setup required.

---

## ✨ Features

- 📋 **Workout Logging** — Record your exercises, sets, reps, and weights
- 📊 **Progress Visualization** — Track improvements over time with interactive charts
- 🗓️ **Session History** — View past workout sessions at a glance
- ⚡ **Fast & Lightweight** — Powered by Streamlit for instant web deployment
- 🌐 **Browser-based** — No app installation needed; runs entirely in the browser

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- pip

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Vidisha1101/PulseFit.git
cd PulseFit

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app
streamlit run PulseFit/app.py
```

The app will open in your browser at `http://localhost:8501`.
